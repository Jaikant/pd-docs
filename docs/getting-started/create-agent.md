
# Create agent
**Estimated Time: 1 minute**

### Sign In
- Sign in to [Predictable Dialogs](https://predictabledialogs.com/sign-in).

### Go to page which creates agents
- Click the card with **+ Create new agent**. 
- Enter an agent name (optional), this creates your chatbot agent.
- Click "+ Add AI" button and enter your system instructions.
- Add files or custom API tools which you want your chatbot to answer from.

Your chatbot agent is now ready with your system instruction.

## Next step

[Choose a channel](/docs/getting-started/choose-channel) to publish your agent on your website or WhatsApp.
